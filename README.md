# nyanfly

냥이를 대포로 날려 얼마나 멀리 보내는지 겨루는 원버튼 물리 아케이드.
브라우저에서 바로 돌아가고, 빌드 과정과 외부 의존성이 없다.

## 조작

버튼은 하나다. 마우스 클릭, 화면 터치, 스페이스바가 모두 같다.

1. 첫 클릭으로 **각도**를 확정한다.
2. 두 번째 클릭으로 **파워**를 확정한다. 게이지 끝에 맞출수록 세다.
3. 비행 중 구름·새·지면에 **닿는 순간** 클릭하면 가속한다. 정확할수록 `완벽!`이
   뜨고, 이어서 성공하면 콤보가 쌓여 보너스가 커진다.

한 판에서 번 츄르로 업그레이드를 사면 다음 판이 더 멀리 간다. 기록은 업그레이드가
절반, 타이밍 실력이 절반쯤 좌우한다.

## 실행

```bash
node tools/serve.mjs
```

`http://localhost:5173/` 를 연다. ES 모듈을 쓰므로 `file://` 로는 열리지 않는다.

## 구조

```
js/sim/     결정론 시뮬레이션 — 물리, 충돌, 지형 생성, 업그레이드 효과
js/render/  그리기 전용 — 카메라, 스프라이트 캐시, 입자
js/ui/      화면과 버튼
js/net/     랭킹 통신
tools/      개발용 정적 서버, 밸런스 점검
tests/      시뮬 테스트
```

핵심은 시뮬과 표현의 분리다. 한 판의 결과는 `{seed, levels, inputs}` 만으로 언제
어디서나 똑같이 재현된다. 덕분에 상위 기록의 유령 리플레이, 서버에서의 기록 검증,
데일리 코스의 공정성이 같은 구조 하나에서 나온다. 자세한 규칙은 [CLAUDE.md](CLAUDE.md),
설계 근거는 [설계 문서](docs/superpowers/specs/2026-09-22-nyanfly-design.md)에 있다.

## 개발

```bash
node --test tests/sim.test.mjs   # 결정론·리플레이·밸런스 테스트
node tools/balance.mjs           # 각도·레벨별 기록 분포
node tools/perf.mjs              # 시뮬 비용, 기록 검증 비용
```

렌더 비용은 브라우저에서 **P 키**를 눌러 계측 표시를 켜서 본다. 창이 숨겨져 있으면
브라우저가 그리기를 건너뛰어 측정값이 의미 없다.

## 랭킹 (선택)

기본은 이 기기에만 저장되는 로컬 랭킹이다. 서버 랭킹을 쓰려면
`supabase/schema.sql` 을 적용하고 `js/net/config.js` 에 프로젝트 URL과
브라우저 공개용(publishable) 키를 넣는다. secret / service_role 키는 넣지 않는다.
